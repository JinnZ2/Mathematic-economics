Decision-Exposure Coupling




  Decision-Exposure Coupling
  CC0. Co-authored. Status tags: OBSERVED (field account) / DERIVED / PROPOSED.
  Companion to Biological Load Accounting for Truck Drivers.

  Decisions about work are made by people who haven't lived it, using evidence written by
  people who haven't lived it, from rules set under conditions that no longer exist. AI then
  makes decisions faster on top of those inputs. A decoupled input produces a false output,
  whether or not anyone meant it to.


  The decoupling (DERIVED)
     DECOUPLING = {

       "result": "false inputs -> false decisions, accelerated",

  Evidence as sensor (PROPOSED)
  Evidence about a job is a sensor reading. It's only valid if the sensor sits on the substrate
  and measures in common denominators. Otherwise it's a bad sensor, and decisions built
  on it inherit the error.

     SENSOR_VALIDITY = {
       "substrate_coupled": None,           # measured where the work and the body
     actually are?
       "common_denominators": {
         "energy_accounting": None,         # joules, hours, calories, fuel in vs out
         "biological_needs": None,          # homeostasis, sleep, sanitation, thermal,
     social
         "responsibility_span": None,       # hours liable, not hours logged
       },
       "same_scale_both_sides": None,       # no false denominator
       "staleness": None,                   # see STALENESS
       "provenance": None,                  # see PROVENANCE
     }


     # None = unassessed (void): neither pass nor fail
     # any field False -> bad sensor -> reading decoupled -> exclude or tag
     DERIVED
     # all True -> valid sensor
     # good decisions require good sensors; trusting bad sensors = deciding on
     noise
