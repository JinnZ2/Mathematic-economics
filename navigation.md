## The Core Equations - Plain English Explanations

### 1. Value Creation vs. Value Extraction (VE/VL Ratio)

**What it measures:** Are people getting rich by *making things* or by *taking from others*?

**The math:**

```
VE/VL = Money extracted by capital / Value created by labor

< 0.1 = Productive (Adam Smith's capitalism)
> 0.3 = Extractive (mercantilism/rentier economy)
```

**Current US:** VE/VL ≈ 0.4 (highly extractive)

**What this means:** For every dollar workers create, capital extracts 40 cents without contributing equivalent production. That’s not Smith’s capitalism - it’s extraction.

-----

### 2. Socialist Infrastructure Dependency (SID)

**What it measures:** How much does “private” business actually depend on collectively-funded systems?

**The math:**

```
SID = Collective resources used / (Collective + Private resources)

0 = Pure private
1 = Pure collective
```

**Current US businesses:** SID ≈ 0.6-0.75 (60-75% dependent on collective infrastructure)

**What this means:** “Private” businesses are majority-dependent on:

- Government-built roads
- Government-funded education of workers
- Government-enforced legal system
- Government-created money
- Government-protected banking system

These are collectively-funded systems. That’s socialism. We just don’t call it that.

-----

### 3. Risk Distribution Inequality (RI)

**What it measures:** Who actually bears the risk in the economy?

**The math:**

```
RI = (Risk borne by workers per person) / (Risk borne by investors per person)

1 = Equal risk distribution
>1 = Workers bear more risk
```

**Current US:** RI ≈ 4.0 (workers bear 4x more risk than investors)

**What this means:** The claim “investors deserve more because they take more risk” is mathematically false. Workers bear:

- Job loss risk (investors are diversified)
- Healthcare loss risk (investors have independent wealth)
- Wage volatility (investors have stable portfolios)
- Retirement insecurity (investors have guaranteed wealth)

Workers take MORE risk but receive LESS reward. That’s not capitalism - it’s extraction.

-----

### 4. Democracy Index (DI)

**What it measures:** How concentrated is decision-making power?

**The math:**

```
DI = Variance in decision-making power across individuals

0 = Perfect democracy (everyone equal)
∞ = Pure oligarchy (infinite concentration)
```

**Current US:** DI ≈ 100,000:1 power ratio (CEO to worker)

**What this means:** A CEO with $50M and board access has roughly 100,000 times more decision-making power than a worker with $5,000. That’s not democracy - it’s oligarchy.

-----

### 5. Upward Wealth Flow Rate (UFR)

**What it measures:** Which direction is wealth flowing?

**The math:**

```
UFR = Rate of wealth accumulation by top 1% / Rate for bottom 50%

1 = Balanced flow
>1 = Upward flow (extraction)
<1 = Downward flow (redistribution)
```

**Current US:** UFR ≈ 30 (top 1% accumulating 30x faster than bottom 50%)

**What this means:** Wealth is rapidly concentrating upward. If you hear “socialist redistribution,” check the math. The redistribution is happening - upward, toward the wealthy.

-----

### 6. Money Socialist Index (MSI)

**What it measures:** Who actually creates the money supply?

**The math:**

```
MSI = Government-created money / Total money supply

Physical currency: 100% government
Electronic money: Created through government-regulated fractional reserve
Federal Reserve: 100% government
Legal tender laws: 100% government enforcement
```

**Current US:** MSI ≈ 0.98 (98% of money is government-created or government-regulated)

**What this means:** The money system is socialist. Not “socialist-leaning” or “partially socialist.” It’s 98% collectively created and managed. We just don’t acknowledge it.

-----

### 7. Bailout Socialism Coefficient (BSC)

**What it measures:** When things go wrong, who gets rescued?

**The math:**

```
BSC = Government rescue funds / Private losses

0 = No bailouts (pure capitalism)
1 = Full coverage (socialism)
>1 = Government pays more than losses
```

**2008 Financial Crisis:**

- Banks: BSC = 3.5 (received 3.5x their losses in bailouts)
- Homeowners: BSC = 0 (received nothing)

**What this means:** Socialism for the rich, capitalism for the poor. The system socializes losses upward and privatizes gains.
